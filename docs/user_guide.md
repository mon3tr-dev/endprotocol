# 用户使用指南

本文档面向 EndProtocol 最终用户，说明账号登录、仪表板、游戏启动器、系统托盘与设置的使用方法。

---

## 1. 账号登录

进入「账户」页面，点击「添加账户」，选择登录方式：

| 方式 | 说明 |
| --- | --- |
| 手机号 + 密码 | 森空岛 / 鹰角通行证 账号密码登录 |
| 短信验证码 | 输入手机号获取短信验证码后登录 |
| 二维码扫码 | 用森空岛 / 鹰角通行证 App 扫描登录二维码 |

多角色账号登录成功后，会弹出角色选择窗口，选择要同步的角色。登录后账号出现在账号列表中，支持批量登出与账号切换。

凭证（cred / token）会自动检查与刷新，支持懒加载与手动重试。后台任务每 300 秒刷新一次账号数据。

## 2. 仪表板

仪表板基于可拖拽卡片网格，支持多标签页分组。

### 添加与编辑卡片

- 点击右下角悬浮按钮或侧边栏添加卡片
- **长按卡片约 1.2 秒**进入编辑模式，随后可拖拽调整位置与顺序
- 右键卡片可切换角色、打开设置、选择勋章、切换领域或删除
- 通过标签页把卡片分组管理，标签页支持自定义名称、图标与标签

### 内置卡片

| 卡片 | 展示内容 |
| --- | --- |
| 账户概览 | 昵称、头像、等级、世界等级、服务器、主线进度、角色/武器/档案数量 |
| 进度条 | 理智（含恢复倒计时）、每日活跃、每周事务、通行证等级 |
| 角色列表 | 支持单列 / 双列 / 三列显示模式 |
| 每日签到 | 今日与明日奖励、签到按钮、自动签到开关 |
| 成就勋章 | 蚀刻章勋章墙，六边形裁切图标与等级解析 |
| 帝江号飞船 | 舱室等级与驻留干员的情绪、信赖 |
| 领域信息 | 等级经验、资金与上限、据点干员、工厂 |

## 3. 角色数据

角色浏览器支持按**职业 / 星级 / 属性 / 武器 / 主词条 / 副词条**六维筛选。

角色详情包含：技能、天赋、潜能、精英化、模组。

Wiki 数据集成：词条目录、物品详情、升级材料解析、技能描述富文本渲染。

---

## 4. 抽卡记录

- 完整抽卡历史，支持角色池与武器池分别同步，增量拉取（遇本地已有记录即停止翻页）
- 卡池分类：全部 / 限定 / 联合 / 标准 / 武器
- 多维筛选：卡池、关键词、星级、仅新获取、仅免费
- 实时同步进度（进度弹窗可关闭后后台继续）
- ECharts 图表：星级分布饼图、6★ 间隔分布直方图（含期望线）、6★ 累计曲线、卡池保底横向条形图

## 5. 游戏启动器（《终末地》）

进入标题栏的模式切换按钮进入**游戏模式**。

### 基本流程

1. 在操作面板选择渠道（官服 / B 服 / 国际服 / Google Play），并指定安装目录——目录会被自动扫描并识别渠道
2. 若目录为空则执行**安装**；已有安装则检测版本并提供**更新**
3. 可选操作：
   - **校验修复**：快速或完整校验，损坏文件自动重新下载
   - **预下载**：提前下载官方预发布补丁分卷
   - **切换渠道**：在已安装渠道之间迁移，含进度与取消回滚
   - **启动游戏** / **结束进程**
4. 底部信息栏展示官方 Banner 与公告，点击在内置浏览器中打开

### 渠道

四个渠道：官服（`official`）、B 服（`bilibili`）、国际服（`global`）、Google Play（`google_play`）。

渠道自动识别依据安装目录中的标记文件（`PCGameSDK.dll`、`hgsdk.dll`、`gfsdk.dll`、`glextra.dll` 等）判定。

## 6. 系统托盘

- 关闭主窗口时默认弹出询问（可在设置中改为直接关闭或最小化到托盘）
- 双击托盘图标唤起主窗口（跨虚拟桌面强制置顶）
- 右键弹出托盘面板（独立的 288×376 无边框窗口）
- 面板右上角徽标显示所选账号的游戏账号等级；正文展示理智（含倒计时）、每日活跃、每周事务与通行证四条进度
- 可指定托盘展示的账号；托盘数据由主进程定期推送

## 7. 设置

| 分组 | 可配置项 |
| --- | --- |
| 通用 | 语言、切换账号时刷新、详情懒加载、Wiki 预加载、关闭行为、托盘账号 |
| 游戏启动 | 校验修复线程数 |

| 更新 | 更新通道（稳定 / 预览）、更新源（GitHub / 镜像）、版本信息 |

## 8. 开发者工具

开启开发者模式后可见：

- **日志查看器**：前端 + 后端日志，支持来源与级别筛选
- **Wiki 数据调试**：目录 / 角色 / 武器词条转储
- **用户信息转储**
- **图片缓存管理**：智能 / 手动模式，条目数与容量上限、统计表、一键打开缓存目录

---

## 9. 应用数据目录

所有本地数据集中存放在：

```
%LOCALAPPDATA%\cn.msk-network.endprotocol\
├── app_config.json          # 全部应用配置与卡片设置
├── image_cache/             # 图片缓存（avatars、skill_icons、weapon_icons 等 9 类）
├── backgrounds/             # 自定义背景图
├── wiki_detail_cache/       # Wiki 词条磁盘缓存
├── gacha_records/           # 抽卡记录（按 userId_serverId 分文件）
└── logs/                    # 日志 app-<日期>.log
```

---

## 10. 更新系统

- **双更新通道**：稳定版 (Stable) 与预览版 (Preview)
- **双更新源**：GitHub Releases 与 Cloudflare R2 镜像（`updates.msk-network.cn`）
- **应用内更新**：Tauri updater 插件 + minisign 签名验证，含更新日志、下载进度与取消
- **启动自动检查**：启动 3 秒后自动检查更新

Windows、macOS 与 Linux 均通过 Tauri updater 插件更新，下载包经 minisign 签名验证。
