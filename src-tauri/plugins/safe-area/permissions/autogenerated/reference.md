## Default Permission

Default permissions for the safe area plugin.

#### This default permission set includes the following:

- `allow-get-safe-area-insets`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`safe-area:allow-get-safe-area-insets`

</td>
<td>

Enables the get_safe_area_insets command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`safe-area:deny-get-safe-area-insets`

</td>
<td>

Denies the get_safe_area_insets command without any pre-configured scope.

</td>
</tr>
</table>
