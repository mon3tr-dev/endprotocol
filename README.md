# EndProtocol

**森空岛账号助手 + 《明日方舟：终末地》启动器** — 一款为干员量身打造的跨平台桌面客户端。

---

## 一句话概括

EndProtocol 把“森空岛数据看板”和“《终末地》游戏启动器”放进同一个窗口。登录多个账号、查看干员 / 抽卡 / 区域与帝江号数据、每日签到，管理游戏安装、渠道切换与 Steam 集成，全程无需切换应用。

---

## 核心功能

### 森空岛数据端

- **多账号管理**：手机号/密码、短信验证码、二维码三种登录方式，支持多账号列表与快速切换
- **角色数据**：按职业、星级、属性、武器六维筛选干员，查看技能、天赋、潜能与模组
- **抽卡统计**：完整抽卡历史增量同步，ECharts 图表展示六星分布、间距与保底曲线
- **每日签到**：今日/明日奖励一览，支持自动签到开关
- **区域与帝江号**：独立页面查看大世界区域等级、货币与基建建设点，以及帝江号舱室等级与派驻干员的心情、信赖
- **成就勋章**：蚀刻章勋章墙，六边形图标与等级解析
- **可拖拽仪表板**：9 种内置卡片（账户信息、账户进度、干员列表、每日签到、成就勋章、区域信息、帝江号、系统资源、待办），自由拖拽布局，多标签页分组管理

### 《终末地》游戏启动器

- **四渠道支持**：官服、B 服、国际服、Google Play
- **渠道自动识别**：根据安装目录标记文件自动判定当前渠道
- **安装 / 更新**：远端清单比对、差分下载、断点续传、MD5 校验
- **校验与修复**：快速 / 完整两档，损坏文件自动重新下载
- **预下载**：提前下载官方预发布补丁分卷，抢先准备新版本
- **渠道切换**：五阶段流水线迁移，支持取消与回滚
- **Steam 集成**：一键添加为 Steam 第三方游戏，自动提取游戏图标，可选 Overlay 注入与管理员快捷方式
- **启动方式**：进程检测、一键启动 / 结束进程，支持 DX11 强制、免启动器启动、静默启动与自定义命令行

### 全屏游戏模式

一键切换到沉浸式游戏外壳，背景图 / 背景视频随渠道变化，底部信息栏展示 Banner 轮播与公告。点击 Banner 或公告会在应用内以原生浏览器打开（支持前进 / 后退 / 刷新，禁嵌站点也能正常访问），切换模式时自动挂起 / 恢复浏览器。

### 系统托盘

双击托盘图标唤起主窗口，右键弹出面板查看所选账号的理智、活跃、事务与通行证进度。关闭行为可配置（关闭 / 最小化到托盘 / 每次询问）。

### 应用自更新

稳定版与预览版双通道，GitHub Releases 与 Cloudflare R2 镜像双源，应用内下载并经 minisign 签名验证，启动 3 秒后自动检查更新。

### 网络与稳定性

- **网络代理**：HTTP / SOCKS5，支持一键导入系统代理、自动检测与连通性测试
- **崩溃诊断**：崩溃提示、日志导出、错因判断与 API 熔断保护
- **开发者工具**：需手动开启的开发者模式，提供网络抓包与调试入口

### 个性化体验

- 玻璃拟态 UI，浅色 / 深色 / 跟随系统主题
- 6 组预设强调色 + 自定义配色（HSV/HSL 取色器 + 屏幕吸管）
- 简体中文与英文双语言
- 自定义背景图与透明度，Windows 亚克力窗口效果

## 快速上手

### 下载

从 [GitHub Releases](https://github.com/soldiereleven/endprotocol/releases) 下载适用于你平台的安装包：

| 平台 | 格式 |
| --- | --- |
| Windows x64 | NSIS 安装程序 (`.exe`) |
| Linux x64 | AppImage |
| macOS Intel / Apple Silicon | DMG |

### 安装与启动

1. 运行安装程序完成安装
2. 启动 EndProtocol，进入「账户」页面点击「添加账户」
3. 选择登录方式（手机号 + 密码 / 验证码 / 扫码）完成登录
4. 多角色账号登录后在弹窗中选择要同步的角色
5. 回到仪表板，添加卡片、长按进入编辑模式即可拖拽布局
6. 侧边栏可进入「区域信息」「帝江号」「抽卡记录」「成就勋章」「待办」等独立页面

### 启动游戏

1. 点击标题栏进入**游戏模式**
2. 在操作面板选择渠道并指定安装目录（目录为空则执行安装，已有安装则检测更新）
3. 点击「启动游戏」即可进入《终末地》
